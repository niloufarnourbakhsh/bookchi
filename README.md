# Bookchi | Online Bookstore

فروشگاه آنلاین کتاب توسعه‌یافته با Laravel و PHP

## معرفی پروژه

**Bookchi** یک فروشگاه آنلاین کتاب است که با استفاده از PHP و فریم‌ورک Laravel توسعه داده شده است. این پروژه شامل بخش مدیریت کتاب‌ها، نویسندگان و انتشارات و همچنین قابلیت سبد خرید برای کاربران است.

ساختار پروژه با تفکیک مسئولیت‌ها در قالب سرویس‌ها و ماژول‌های مجزا طراحی شده است. همچنین برای مدیریت آپلود تصاویر و فایل‌ها، از یک سرویس مجزا در داخل پروژه استفاده می‌شود.

## قابلیت‌ها

- مدیریت کتاب‌ها از طریق بخش مدیریت
- سبد خرید و اضفه کردن کاب به سبد خرید

##

- مدیریت اطلاعات نویسندگان
- مدیریت اطلاعات انتشارات
- سبد خرید مبتنی بر Session
- تفکیک مسئولیت‌ها با استفاده از سرویس‌ها و ماژول‌های مجزا
- استفاده از سرویس مستقل در ساختار برنامه برای مدیریت آپلود تصاویر و فایل‌ها

## تکنولوژی‌ها

- PHP
- Laravel
- Session
- Git و GitHubساختار پروژه

در طراحی پروژه تلاش شده است مسئولیت‌های مختلف در سرویس‌ها و ماژول‌های مجزا قرار بگیرند تا ساختار کد خواناتر و نگهداری و توسعه‌ی آن ساده‌تر باشد.
